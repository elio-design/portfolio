# Elio Costa Portfolio

A responsive single-page portfolio website built from the uploaded CV and portrait.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation
- `assets/profile.jpg` — uploaded portrait

## Run locally
Open `index.html` in a browser.

For the best local preview, serve the folder with any simple static server, for example:
`python -m http.server`

## Content source
The portfolio content is based on the supplied Elio Costa CV. The site does not add social profiles or claims that were not present in the CV.
